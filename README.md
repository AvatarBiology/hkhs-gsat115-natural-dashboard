# HKHS 115學測自然科試題分析儀表板

115 學年度學科能力測驗・自然考科試題分析互動儀表板，供湖口高中教師進行跨科目 × 跨題型試題分析。

## 線上使用

直接開啟本頁面的 GitHub Pages 網址即可使用（建議用 Chrome / Edge 瀏覽器）。

🔑 **登入密碼**：`請向管理員索取`（開啟頁面後輸入即可進入）

## 功能一覽

| 頁籤 | 說明 |
|------|------|
| 總覽 | 科目 × 題型答對率交叉表、答對率 × 鑑別度散佈圖（可複選科目篩選）、迷思標籤統計 |
| 校際對照 | 湖口高中 vs 全國答對率差異排行，落後題目自動標示教學建議 |
| 題目明細 | 48 題逐題瀏覽：雙母體選項分佈圖、試題本預覽、五能力組曲線 |
| 迷思分析 | 強誘答、高分組陷阱、低鑑別、頂尖反轉排行；閾值可自訂即時重算 |
| 🧭 引導策略 | 9 種迷思標籤對應的課堂引導手法（含步驟與時間），與題目互相連動 |
| 資料與標註 | 科目 / 題型標註對照表（可編輯、匯出） |
| 📖 使用指南 | 教師使用說明 |

## 資料來源

- 湖口高中 115 學測自然考科校內統計（答對率、鑑別度、選項分析）
- 大考中心公布之全國統計資料（全體考生約 78,386 人）
- 科目分類經公開逐題解析＋教師評析交叉驗證

## 技術說明

- 單一 HTML 檔案，無後端、無需建置，離線可開啟
- 登入密碼為前端驗證（SHA-256），簡易門禁
- 標註修改儲存於瀏覽器 localStorage；欲永久生效請匯出 CSV 回傳管理者
